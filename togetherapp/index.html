ONE-TIME APP SETUP

Enable Google sign-in

This app needs its own Google OAuth credentials before anyone can connect. You don’t need to give Together your Google password.

  1. Open Google Cloud Console ↗ and create or select a project.
  2. Under APIs & Services → Library, enable Google Calendar API.
  3. Open Google Auth Platform. Configure Branding with an app name and support email. Choose an External audience, keep the app in Testing, and add your Google email as a test user.
  4. Under Data Access, add calendar.freebusy and calendar.events.owned scopes.
  5. Under Clients, create an OAuth client of type Web application. Add this exact authorized redirect URI:http://localhost:4173/auth/google/callback
  6. Copy .env.example to .env in the project folder. Fill in GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET locally. Don’t paste the secret in chat.
  7. Restart the app server with npm start, reopen this page, and click Connect Google Calendar.

Use a normal browser such as Chrome or Edge for Google sign-in. If Google blocks an embedded browser, open http://localhost:4173 in that browser. This development connection lasts until the server restarts or the session expires.
